# スイッチ内VLANのコンパクト表示

「L2 VLAN」タブではスイッチ（roleにswitchを含む機器、または論理STACK）のaccessポートを、機器とVLAN定義IDの組み合わせごとに一つの枠へまとめます。枠内は物理ポート名の2列の一覧です。長い名前は省略表示し、完全な名前とIF IDをツールチップに保持します。同じ枠の所属線は一つへ集約し、線のdata-endpointsには全IF IDを保持します。個々のポート定義・物理接続・YAMLは変更しません。

VLAN枠をクリックするとVLAN定義と参照を強調します。枠内のポートを選ぶと全レイヤーの個別行へ切り替え、そのポートの層間対応とYAML定義を確認できます。trunk、LAG、SVI、routed、ホストのbond/teamは別の役割として詳細行を維持します。「全レイヤー」では従来の個別行と対応線を維持します。

例: gran-c-switch1はVLAN 1（1ポート）、VLAN 10（7ポート）、VLAN 100（24ポート、49・50を含む）、VLAN 200（18ポート）の4枠になります。共有ネットワーク枠とは別に、各スイッチ内でポート表示を集約する機能です。YAML上のLAGやbondへ変換する機能ではありません。

検証: test_compact_switch.pyで50ポート4VLANと3台の48ポート機器を検証し、高さが従来の1/3未満になること、全accessポートの保持、集約線の全メンバー、全レイヤー詳細表示を確認します。compact-switch.spec.tsで集約枠・YAML連携・Escape解除・48番ポートからの層間追跡を確認します。

# L2の共有VLAN枠

L2図では、l2.vlans の定義IDごとに共有枠を一つ描きます。機器ごとの枠とインターフェース行は保持し、各行の接続点から所属VLAN枠へ線を引きます。trunkはtagged_vlansに含まれる各枠へ接続します。

- 同じ定義IDは複数機器で共有します。tagが同じでも定義IDが異なれば別枠です。
- VLAN枠のラベル・枠・所属線をクリック、または枠へフォーカスしてEnter/Spaceを押すと選択します。所属する行と線を強調し、他VLANを薄くします。選択はマウスを離しても保持され、同じ枠の再選択やEscapeで解除できます。
- ポート行からのL1・L2・L3層間追跡、VLANのYAML定義・参照の強調を維持します。
- 拠点・機器群・機器での絞り込みでは、表示範囲内のメンバーのみを接続します。
- bridgeは機器内の転送関係として従来の表示を保持します。VLAN枠は物理接続や疎通を保証しません。
- YAMLスキーマと保存形式は変更しません。SVG出力にも共有枠を含めます。

検証: test_shared_vlan.py は共有枠の一意性、異なる定義IDの同番号VLAN、空のVLAN、trunk所属、ポート行と層間対応の保持を検証します。frontend/e2e/shared-vlan.spec.ts は選択の維持、所属行・線の強調、trunk、YAML連携、絞り込み、層間追跡を確認します。

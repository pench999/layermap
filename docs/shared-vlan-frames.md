# L2の共有VLAN枠

L2図では、l2.vlans の定義IDごとに共有枠を一つ描きます。機器ごとの枠とインターフェース行は保持し、各行の接続点から所属VLAN枠へ線を引きます。trunkはtagged_vlansに含まれる各枠へ接続します。

- 同じ定義IDは複数機器で共有します。tagが同じでも定義IDが異なれば別枠です。
- VLAN枠のラベル・枠・所属線をクリック、または枠へフォーカスしてEnter/Spaceを押すと選択します。所属する行と線を強調し、他VLANを薄くします。選択はマウスを離しても保持され、同じ枠の再選択やEscapeで解除できます。
- ポート行からのL1・L2・L3層間追跡、VLANのYAML定義・参照の強調を維持します。
- 拠点・機器群・機器での絞り込みでは、表示範囲内のメンバーのみを接続します。
- bridgeは機器内の転送関係として従来の表示を保持します。VLAN枠は物理接続や疎通を保証しません。
- YAMLスキーマと保存形式は変更しません。SVG出力にも共有枠を含めます。

検証: test_shared_vlan.py は共有枠の一意性、異なる定義IDの同番号VLAN、空のVLAN、trunk所属、ポート行と層間対応の保持を検証します。frontend/e2e/shared-vlan.spec.ts は選択の維持、所属行・線の強調、trunk、YAML連携、絞り込み、層間追跡を確認します。

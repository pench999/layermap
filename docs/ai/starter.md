# 別のAIで使う手順

1. 「LayerMap-YAML作成指示書.md」をAIのチャットへ添付するか、全文を最初に貼り付けてください。プロジェクト指示に登録する方法でも使えます。
2. 既存構成の修正なら、そのYAMLも一緒に渡してください。
3. 下の開始プロンプトを貼り、構成を文章で伝えてください。
4. 生成されたYAMLはLayerMapへ読み込んで確認してください。

## 開始プロンプト（コピー用）

添付の「LayerMap-YAML作成指示書.md」に従い、LayerMap用YAMLの作成・修正を手伝ってください。
不明なIP・配線・ポート・シリアルNoは推測せず、必要な確認事項だけを質問してください。
既存YAMLのID・コメント・関係のない設定を保持し、対象の定義と参照をセットで修正してください。
回答は「変更内容」「読み込めるYAML全文」「未確認事項」「検証状況」の順にしてください。
実行できない検証を成功と報告しないでください。

これから構成情報を伝えます。

## 依頼の例

- 新規: 「社内LANを新規作成したいです。機器とIPの一覧を次に渡すので、不足を確認してください。」
- 複製: 「このYAMLを正本に、SW-01と同じVLAN設定のSW-02を追加してください。管理IPは192.0.2.12/24です。シリアルNoは未確認です。」
- 配線不明: 「PCのeth0はSW-01に有線接続していますが、スイッチ側ポートが未確認です。」
- 50ポート: 「port1はVLAN1、port2〜8はVLAN10、port9〜30と49〜50はVLAN100、port31〜48はVLAN200です。49〜50は10Gbpsです。L1/L2/bindingsを省略せず列挙してください。」
- 管理IP: 「L2スイッチの管理IPを、VLAN1のSVIとして追加してください。IPとプレフィックスは次に伝えます。」
- 表示グループ: 「net-aとnet-bの個別CIDRを維持し、l3.subnet_groupsでサービスNWの一枠にまとめてください。」
- エラー: 「添付YAMLとLayerMapのエラーを照合し、元ファイルを残して最小限の修正版を作ってください。」

## 同梱ファイル

- LayerMap-YAML作成指示書.md: AIへ読み込ませる自己完結した仕様・作業指示・完全サンプル。
- 検証用サンプル.yaml: 指示書末尾と同じ完全サンプル。架空の機器・アドレスです。

この資料は他のAIが必ず正しいYAMLを生成する保証ではありません。生成結果をLayerMapで検証してください。機密情報を別のAIへ渡す際は、所属組織の利用ルールに従ってください。

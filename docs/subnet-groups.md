# L3サブネットの表示グループ

l3.subnetsのcidrは一つずつ保持します。l3.subnet_groupsの各要素にid、任意のlabel、members（サブネットIDの配列）を指定すると、所属CIDRと接続線を一つの外枠にまとめます。グループ未指定のサブネットは従来どおり独立表示します。

```yaml
l3:
  subnets:
    - {id: net-a, cidr: 192.0.2.0/24}
    - {id: net-b, cidr: 198.51.100.0/24}
  subnet_groups:
    - id: service
      label: サービスNW
      members: [net-a, net-b]
```

- グループ枠の選択で所属するL3行・線とYAML定義を強調します。各CIDRの選択とIFの層間追跡も維持します。
- 参照切れ、グループID重複、空members、メンバー重複、複数グループへの所属はエラーです。
- IPv4とIPv6を同じ表示グループへ含められます。IP所属、経路、VPN、重複検出は個々のサブネット定義を使います。表示グループに通信やルーティングの意味はありません。
- 絞り込みでは表示対象メンバーだけを残し、空になったグループは省略します。全YAMLの保存内容は維持します。
- 拠点YAML統合ではグループIDと全members参照も拠点IDで変換します。
- グループ定義と所属は保持・表示の要素数予算に計上します。描画グループ数は外枠数として数えますが、サブネット/IF/接続は個別に上限を確認します。

画面サンプル「L3サブネットの表示グループ」でIPv4/IPv6の3ネットワークをまとめた枠と、独立した管理NWを比較できます。グループはYAMLで編集します。
